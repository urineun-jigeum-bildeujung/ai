# 재구매 예측

사용자별 구매 이력을 바탕으로 소비주기와 다음 구매 권장 시점을 산출하는 기능을 관리합니다.

## 디렉터리

- `data_analysis/`: 공개 실제 데이터셋의 구조·분포·재구매 패턴 분석
- 추후 학습, 추론, API 코드는 구현 단계에 맞춰 분리합니다.

## 데이터 사용 원칙

- 공개 실제 데이터는 모델 학습·검증과 합성 데이터 생성 가이드 수립에 사용합니다.
- 자체 서비스 형식의 합성 데이터는 DB·API·배치·예외 처리 시연에 사용합니다.
- 원본 데이터 파일과 개인정보·API 키는 Git에 커밋하지 않습니다.
