# 재구매 예측

사용자별 구매 이력과 마지막 구매 후 경과 시간을 바탕으로 향후 30일 이내 조건부 재구매 확률을 산출합니다. 데이터 분석, 모델 학습·평가, 추론 배치와 결과 저장을 관리합니다.

## 디렉터리

- `data_analysis/`: 공개 데이터 분석, 모델 학습·평가, 추론 배치 및 테스트
- `database/`: 예측 결과 저장 스키마와 조회 계약
- [실행 문서](data_analysis/README.md): 개발 환경과 분석·학습·배치 실행 방법
- [추론 계약](INFERENCE_CONTRACT.md): 모델 아티팩트 및 추론 검증
- [클라우드 데이터 계약](CLOUD_DATA_CONTRACT.md): 서비스 데이터·적재 경계
- [시연 모델 결정](DEMO_MODEL_DECISION.md): AFT 시연 선택과 확인 상태

## 데이터 사용 원칙

- 공개 실제 데이터는 모델 학습·검증과 합성 데이터 생성 가이드 수립에 사용합니다.
- 자체 서비스 형식의 합성 데이터는 DB·API·배치·예외 처리 시연에 사용합니다.
- 원본 데이터 파일과 개인정보·API 키는 Git에 커밋하지 않습니다.

## 모델 비교와 운영 판단

2026-10-04에 사전 고정한 두 모델을 **목데이터 Test 34,895행**에서 비교했습니다.

| 지표 | XGBoost AFT | LightGBM |
| --- | ---: | ---: |
| 30일 IPCW Brier ↓ | 0.166328 | 0.160562 |
| IPCW C-index ↑ | 0.749188 | 0.746836 |
| ECE ↓ | 0.106291 | 0.087274 |

IPCW는 관측 종료로 결과가 확인되지 않은 표본을 고려하는 가중 방식입니다. Brier는 확률 오차, C-index는 재구매 순서 구분, ECE는 예측 확률과 관측률의 차이를 평가합니다.

AFT는 순위 지표가 높았고 LightGBM은 확률 오차와 보정 지표가 낮았습니다. 두 모델 모두 해당 Test에서 과소예측을 보여 **운영 확률 공개와 정기 배치 활성화를 보류**했습니다. Test를 본 뒤 모델을 교체하는 사후 선택도 하지 않았습니다. 이 결과는 실제 사용자 성능을 의미하지 않습니다.
