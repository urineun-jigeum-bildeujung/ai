# 재구매 합성 보정 재현 실험 — 경과 0일 실패 반복

첫 독립 합성 최종 평가에서 경과 0·7일과 저이력 구간의 성능이 일관되지 않아, **새 시드·ID·기간의 합성 생성본**으로 같은 AFT/Isotonic 설정을 다시 검증했다. 이는 기존 최종 평가본을 재학습하거나 그 결과에 맞춰 매핑을 수정한 실험이 아니다. 새 개발본에서 후보 선택 규칙과 지문을 동결한 뒤 새 최종 평가본을 한 번만 열었다.

두 생성본은 기존 Test와 앞선 합성 생성본 이후의 기간에 위치하고, 주문 ID 공간도 분리했다. 파일 지문과 개발/평가 분리 사전검사를 통과했다. 다만 **생성 규칙은 앞선 합성본과 동일**하다. 새 시드에 대한 반복이지 실제 사용자 분포나 다른 생성 메커니즘으로의 일반화 검증은 아니다. 클레임 0건이라는 한계도 같다.

개발본의 외부 Validation에서는 Isotonic이 원본 AFT보다 모든 경과일에서 Brier가 낮았다. 개선량(원본−보정)은 0·7·14·30일 순서로 **+0.119433, +0.231384, +0.365388, +0.483017**이었다. 사용자 단위 Bootstrap 1,000회/seed 42의 95% 구간은 각각 **[+0.084353,+0.155934]**, **[+0.181072,+0.278529]**, **[+0.305213,+0.424033]**, **[+0.372036,+0.589147]**이었다. 개발 결과 SHA-256은 `7b175433b3020af90f3115d8e69b9c7b5b7a77ebcdb1d4bc9ff413ea008c728b`이다. 동결 조건은 `independent_synthetic_calibration_freeze_v3.json`에 기록했다.

판정은 **합성 파이프라인의 전 경과일 일괄 보정 실패, 운영 확률 공개 NO-GO 유지**다. 새 보정 후보를 실험하더라도 이 두 최종 평가본에 맞춰 재선택하거나 튜닝하지 않는다. 별도 개발·미사용 평가 분리, 실제 분포의 독립 검증, 경과일/저이력 성능과 보정곡선의 검토가 선행돼야 한다.
