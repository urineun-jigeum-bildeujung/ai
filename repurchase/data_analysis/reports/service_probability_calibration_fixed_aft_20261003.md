# 고정 AFT 후보의 조건부 확률 보정 재검증

- 목적: 최종 평가 후보로 기록된 AFT `normal`/20회/scale **2.0**의 보정 전후를 비교한다. 이전 보정 실험은 scale 1.0이므로 결과를 고정 후보의 성능으로 사용하지 않는다.
- 입력: 2026-10-03 로컬 읽기 전용 추출본. 주문 44,777건·주문상품 100,487건·상태 이력 259,596건·클레임 1,395건·클레임상품 2,592건·반려동물 13,254건의 건수와 파일 SHA-256을 재확인했다. 두 DB의 추출은 원자적 동일 시점 스냅샷이 아니다.
- 분할: 관측 종료 `2026-10-03T00:00:00+09:00` 가정. 시간순 바깥 Train 70%·Validation 15%; 바깥 Train 안에서 AFT 학습 80%·Isotonic 보정 20%. 같은 내부 Train AFT의 보정 전후 확률을 같은 바깥 Validation 행에서 평가했다. Test는 열지 않았다.

| 경과 | 정답 확인 행 | IPCW Brier 원본 → 보정 | ECE 원본 → 보정 | Brier 개선량 95% 사용자 Bootstrap 구간 |
| --- | ---: | ---: | ---: | ---: |
| 0일 | 13,625 | 0.122805 → 0.122976 | 0.033952 → 0.030839 | -0.000465 ~ +0.000107 |
| 7일 | 11,848 | 0.122005 → 0.120608 | 0.040259 → 0.024336 | +0.000881 ~ +0.001917 |
| 14일 | 10,151 | 0.113243 → 0.111375 | 0.036232 → 0.016685 | +0.001153 ~ +0.002525 |
| 30일 | 6,896 | 0.094590 → 0.093370 | 0.025877 → 0.015018 | +0.000293 ~ +0.002109 |

사용자 단위 쌍 Bootstrap은 시점별 1,000회(seed 42) 수행했다. **0일은 Brier가 0.000171 높아지고 신뢰구간이 0을 포함한다.** 7·14·30일은 Brier가 낮아졌지만, 이 결과만으로 시점별 보정기를 운영에 채택하지 않는다. 네 시점 전체에 동일한 보정 정책을 적용할 근거는 없다. 0일 ECE가 낮아진 것만으로 Brier 악화를 무시하지 않는다.

재현 명령은 `scripts.run_service_probability_calibration`에 `--aft-boost-rounds 20 --aft-loss-distribution-scale 2.0 --landmark-days 0 7 14 30 --bootstrap-replicates 1000`을 지정한다. 로컬 결과 JSON은 `/private/tmp/repurchase-fixed-aft-calibration-20261003.json`이며 원천·코드 SHA-256, 시간 컷, 지표, 보정 매핑, 반복별 Bootstrap 값을 기록한다. 원천 CSV와 JSON은 Git에 올리지 않는다.

이 신뢰구간은 **고정 모델의 평가 표본 변동성**만 반영한다. 학습·보정기의 재학습 변동성, Test 성능, 실제 사용자 성능은 포함하지 않는다. 바깥 Train 전체로 학습한 고정 후보의 기존 지표와도 학습 집합이 달라 직접 비교하지 않는다. 운영 모델·확률 노출·Test 실행 여부는 별도로 결정한다.
