# 재구매 이력 상호작용 보정 — 개발본 비교

## 목적과 경계

기존 단일 Isotonic 보정은 v5 개발본에서 7일·구매 간격 0개 구간의 Brier가 **0.250597→0.251069**로 악화됐다. 동일한 합성 규칙이되 시간·시드·ID 공간이 다른 **v6·v7 개발본**에서 원본 AFT, 단일 Isotonic, 이력 상호작용 로지스틱 보정을 비교했다. v5 외부 Validation과 이미 평가한 이전 최종 생성본은 이 후보의 적합에 사용하지 않았다. v6·v7 최종 평가본은 생성만 했으며 행·라벨·피처를 열지 않았다.

새 후보는 원본 AFT의 log-odds, 구매 간격 0개·1~2개 표시자와 각각의 log-odds 상호작용을 입력으로 사용한다. 3개 이상은 기준 그룹이다. L2 로지스틱 회귀의 `C=1.0`을 고정하고, **내부 보정 구간에서 결과가 확인된 행**의 IPCW 가중치만으로 적합했다. 가중치는 평균 1로 정규화한다. 외부 Validation에서는 같은 AFT 모델·행·IPCW 가중치로 세 후보를 비교한다. 그룹별 예외 규칙이나 운영 fallback을 추가한 것이 아니다.

## 핵심 저이력 구간

| 개발본 | 7일·간격 0개 결과 확인 / 사용자 | 가중 사건률 | 원본·Isotonic·새 후보 평균 확률 | 세 후보 Brier | 새 후보 개선량 Bootstrap 95% 구간 |
| --- | ---: | ---: | --- | --- | --- |
| v6 | 207행 / 145명 | 0.472965 | 0.454893 / 0.552339 / 0.472796 | 0.249596 / 0.255569 / **0.249269** | −0.002133~+0.003097 |
| v7 | 225행 / 154명 | 0.458635 | 0.453396 / 0.537142 / 0.468541 | 0.248104 / 0.254452 / **0.247930** | −0.001984~+0.002339 |

새 후보의 원본 대비 개선량은 각각 **+0.000327, +0.000174**로 매우 작고, 두 사용자 Bootstrap 구간 모두 0을 포함한다. 따라서 저이력 개선이 안정적으로 입증됐다고 말할 수 없다. 그러나 기존 Isotonic의 과대예측과 점추정 악화가 두 개발본에서 반복된 반면, 새 후보는 사전에 정한 **전체 4개 경과일·저이력 8개 구간의 점추정 비악화 개발 스크린**을 두 번 모두 통과했다. 이 스크린은 최종 평가 실행 가능성을 판단하는 보수적 사전 필터이지 운영 확률 공개 승인이나 유의성 검정이 아니다.

## 다음 검증 조건

후보의 입력·L2 설정·동일 모집단 평가·저이력 판정 기준과 코드/원천 지문을 동결한 후, **한 개의 미사용 최종 합성 평가본에서 한 번만** 원본·Isotonic·새 후보를 비교한다. 최종 결과를 보고 설정이나 후보를 다시 고르지 않는다. 전체 및 저이력 Brier, ECE/보정곡선, 사용자 Bootstrap 구간을 함께 보고 어느 구간이라도 악화되면 전체 개선만으로 통과시키지 않는다. 합성 평가가 통과해도 실제 사용자 분포의 독립 검증 전에는 `PUBLISHED`와 정기 CronJob을 승인하지 않는다.
