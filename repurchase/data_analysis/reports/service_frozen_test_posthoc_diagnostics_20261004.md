# 봉인 Test의 사후 오차 구간 진단

## 범위와 해석 제한

2026-10-04 최종 Test에서 이미 고정된 두 모델과 같은 원천·행·30일 IPCW 가중치를 **변경하지 않고**, 오차를 구간별로 분해했다. 새 독립 데이터 평가나 보정 실험이 아니다. 이 결과를 보고 모델·보정 방법을 재선택하지 않는다. 로컬 원천 6종의 SHA-256, 모델 ID, 기존 완료 기록과 전체 Brier 차이(0.00576652)를 대조했다. 개인별 행은 보고서나 Git에 저장하지 않는다.

두 모델은 세 이력 구간 모두에서 관측률보다 낮게 예측했다. AFT와 LightGBM의 전체 Brier 차이 0.005767 중 구매 간격 2개 이상 구간의 기여는 **0.004304(약 74.6%)**다. 이는 LightGBM이 전체 Test에서 더 낮은 Brier를 보인 원인이 단순히 이력 부족 구간에만 있지 않음을 보여준다. 다만 구간 기여는 표본 비중과 오차 크기를 함께 반영하며 인과적 원인 분석은 아니다.

## 다음 결정

- 이 분석은 이미 열린 Test의 **사후 진단**으로만 사용한다. Test에 맞춰 보정기를 적합하거나 모델을 교체하지 않는다.
- 현재 로컬 스냅샷만으로는 새로운 시간 구간의 독립 정답이 생기지 않는다. 별도 생성 데이터는 스트레스 테스트에는 쓸 수 있지만 실제 사용자·미래 운영 성능의 증거가 아니다.
- 새 독립 데이터가 준비되면 데이터 컷·원천/생성 버전·모델/보정 정책을 먼저 고정하고, 동일 모집단에서 Brier·C-index·Calibration과 사용자 단위 Bootstrap을 평가한다. 그 전까지 사용자 확률 노출은 **NO-GO**다.
