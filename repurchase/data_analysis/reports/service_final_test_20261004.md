# 재구매 고정 모델 최종 Test 평가와 운영 판단

## 평가 범위

- 2026-10-04에 로컬 목데이터 스냅샷으로 **봉인된 Test를 1회 평가**했다. 원천 6개 파일, Validation 결과, 고정 모델 2개의 지문 사전검증을 통과했다.
- Test 앵커는 `2026-06-15T03:22:07.988021400+00:00` 이후부터 관측 종료 가정 `2026-10-03T00:00:00+09:00`까지다. 동일한 34,895행과 30일 IPCW 정답·가중치로 두 모델을 비교했다. 정답 확인 24,029행, 평가 시점까지 결과를 확인하지 못한 10,866행이다.
- 비교 대상은 사전 고정한 XGBoost AFT(`normal`/20회/scale 2.0)와 LightGBM이다. Test를 보고 재학습·설정 변경·후보 교체를 하지 않았다.
- 모델 아티팩트 ID는 AFT `ec25eb1bcd8f24ce36a2397c1544cb087cb970af532365de7f8ec900aeb4b7fb`, LightGBM `c897ee3f2357c6873959d067b87b51c3965ca7aefe0d8f95a24cb7e58042a263`이다.

## 결과

| 구간·지표 | AFT | LightGBM | 해석 |
| --- | ---: | ---: | --- |
| Validation IPCW Brier ↓ | **0.121258** | 0.123063 | Test 이전 모델 비교 |
| Validation IPCW C-index ↑ | **0.702086** | 0.696018 | 동일 Validation 19,189행 |

| Test ECE ↓ | 0.106291 | **0.087274** | 두 모델 모두 Validation보다 큼 |

Validation 수치는 당시 Train으로 학습한 모델, Test 수치는 Validation 종료 컷까지 재학습해 고정한 모델의 결과다. 평가 기간·모집단·학습량이 모두 달라 같은 표의 Validation → Test 숫자를 단순한 성능 저하량으로 해석하지 않는다.

Test의 사용자 3,617명을 1,000회 쌍으로 재표본추출했다. `Brier(AFT) − Brier(LightGBM)`의 점추정은 **+0.005767**, 95% percentile 구간은 **[+0.004522, +0.006965]**이며, 양수 반복 비율은 100%다. 이는 **고정 모델·고정 평가 행·고정 IPCW 가중치에서 사용자 구성의 불확실성**만 반영한다. 모델 재학습, 데이터 생성 또는 시간 이동의 불확실성을 포함하지 않는다.

Test의 IPCW 가중 관측 30일 재구매율은 **27.72%**인데 평균 예측 확률은 AFT **17.09%**, LightGBM **19.00%**다. 두 모델 모두 이 모집단에서 과소예측 방향이다. Validation의 가중 관측률은 **15.88%**로 Test보다 **11.84%p 낮다**. 따라서 Validation과 Test의 Brier 차이를 곧바로 모델 자체의 성능 악화나 특정 원인으로 단정하지 않는다. Test의 확률 기준선 Brier는 **0.220481**로 두 모델보다 높다.

| 대상 | 현재 판단 | 이유 |

## 후속 작업과 경계

1. 저장된 Test calibration bin의 위 진단은 완료했다. Validation 대비 모집단 차이는 별도 집계가 필요하다. 현재 결과 파일에는 이력량·상품 prior·사용자 구매 빈도별 Test 성능이 없어, 해당 분석을 수행했다고 주장하지 않는다.
2. 확률 보정 또는 모델 변경은 이 Test를 재사용해 결정하지 않는다. 새 시점의 데이터가 확보되면 별도 시간순 검증 구간을 고정해 재평가한다.
3. dev DB의 AFT `SHADOW` 1회 적재·멱등 재실행 검증은 2026-10-04에 완료했다. 이는 운영 모델 선정이나 사용자 노출 승인이 아니다. 운영 결과의 후보·상태 표시를 결정하기 전까지 `PUBLISHED` 발행과 정기 CronJob은 보류한다.

이 결과는 **목데이터의 로컬 추출본**에 대한 평가다. `order_db`와 `member_db`의 추출은 원자적 동일 시점 스냅샷이 아니며, 실제 사용자 성능이나 운영 환경의 데이터 신선도를 보증하지 않는다. Test 실행 기록의 상태는 `completed`이고 결과 SHA-256은 `be97dc183ee3112d11a3f783d9394fd3dd1fc22a93737d05190eb505d67907b5`다. 원본 CSV, 사용자별 결과와 Bootstrap 반복값은 Git에 올리지 않는다.
