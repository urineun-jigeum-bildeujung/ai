# 재구매 독립 합성 평가 결과 — 운영 확률 공개 NO-GO 유지

개발용 합성 데이터에서 선택한 IPCW 가중 Isotonic 보정 매핑과 AFT 20 rounds/scale 1.0을 사전 동결한 뒤, 별도 생성한 최종 합성 데이터에 **한 번** 적용했다. 최종 평가용 데이터를 보고 후보·파라미터를 다시 선택하지 않았다. 이 결과는 합성 파이프라인 검증이며 실제 사용자 성능을 뜻하지 않는다.

- 개발용 주문 2,700건, 최종 평가용 주문 2,633건. 두 생성본의 주문 ID·시점·난수 시드는 분리됐다.
- 최종 평가 출력: `/private/tmp/repurchase-synthetic-final-evaluation-20261005-v2.json`; SHA-256 `92e2784b614155b36de8b77bfd27fe5414884fd89dd8dd234e91422a09ee17e4`.
- 모델·매핑 재현, 입력 지문, 분리 사전검사를 통과한 뒤에만 최종 피처·라벨을 열었다. 예측 기간 30일, 사용자 단위 Bootstrap 1,000회/seed 42.

| 구매 후 경과 | 확인된 결과 | 원본 AFT Brier | Isotonic Brier | 점추정 개선량 | 개선량 95% 구간 | 원본/보정 ECE |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0일 | 2,502 | 0.197223 | 0.212239 | −0.015016 | −0.035959~+0.003919 | 0.107304 / 0.152776 |
| 7일 | 2,488 | 0.233913 | 0.235562 | −0.001650 | −0.035199~+0.028496 | 0.189910 / 0.178418 |
| 14일 | 2,456 | 0.273501 | 0.199100 | +0.074401 | +0.037659~+0.106028 | 0.326974 / 0.163251 |
| 30일 | 1,501 | 0.393806 | 0.099063 | +0.294743 | +0.267380~+0.322404 | 0.543960 / 0.067826 |

개선량은 원본 AFT Brier에서 보정 Brier를 뺀 값이다. 0·7일의 95% 구간은 0을 포함하므로, 해당 경과일의 악화가 통계적으로 확정됐다는 뜻은 아니다.

기반 AFT의 IPCW C-index는 경과 0·7·14·30일 순서로 0.705545, 0.696352, 0.686426, 0.635527이었다. 이는 원본 AFT의 순위 지표이며 확률 보정 자체의 순위 개선을 의미하지 않는다. 확률 구간별 예측값·실제 사건률은 결과 JSON의 `calibration_bins` 58행에, 이력별 Brier는 `low_history_subgroups` 48행에 보존했다.

특히 경과 0일의 과거 구매 간격이 없는 174행에서 Brier는 원본 0.217192에서 보정 0.277249로 높아졌고, 간격 1~2개인 348행에서도 0.168541에서 0.272001로 높아졌다. 전체 평균의 특정 경과일 개선만으로 저이력 사용자에게 보정을 일괄 적용할 수 없다.

결론: 이 동결 Isotonic 후보는 최종 합성 평가의 **모든 경과일·저이력 구간에서 일관된 개선을 보이지 않았다.** 운영 확률 공개는 계속 NO-GO이며 `PUBLISHED` 노출이나 정기 CronJob 활성화 근거로 사용하지 않는다. 이후 방법을 바꾸려면 이 최종 생성본에 맞춰 재튜닝하지 않고, 새 개발 데이터와 새 미사용 평가 데이터를 별도로 마련해야 한다. 기존 UCI Test·dev SHADOW에서 확인된 확률 품질 문제도 이 합성 결과로 해소됐다고 볼 수 없다.

## 재검증과 다음 실험의 경계

`scripts.summarize_independent_synthetic_final`은 이미 생성된 최종 결과 JSON만 읽어 경과일별 Brier·ECE·사용자 Bootstrap 구간과 저이력 구간을 대조한다. 학습·보정·후보 선택은 하지 않으며, 모집단이나 쌍 비교가 누락되면 요약을 거부한다. 로컬 재검증 예:

```sh
cd repurchase/data_analysis
.venv/bin/python -m scripts.summarize_independent_synthetic_final \
  --input /private/tmp/repurchase-synthetic-final-evaluation-20261005-v2.json \
  --output /private/tmp/repurchase-synthetic-final-summary-20261005.json
```

다음 보정 실험은 **새 개발본에서만** 설계·적합·선택하고, 선택 전에 새 최종 평가본과 판정 규칙을 동결한다. 최소 비교 대상은 보정하지 않은 AFT, 현재 Isotonic, 그리고 새 개발본에서 선정할 보정 후보이며, 0·7·14·30일 경과와 간격 0개/1~2개 구간을 같은 모집단에서 비교한다. Brier·ECE·Calibration curve·사용자 단위 Bootstrap을 함께 보고, 경과일별 점추정뿐 아니라 구간과 저이력 악화를 확인한다. 새 합성 평가가 통과하더라도 실제 사용자 분포의 독립 검증과 운영 계약 확인 전에는 공개 승인으로 연결하지 않는다.
