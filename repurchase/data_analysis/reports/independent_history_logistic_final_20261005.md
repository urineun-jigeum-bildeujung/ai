# 재구매 이력 상호작용 보정: 독립 합성 최종 평가

## 결론

사전 동결한 후보와 판정 규칙을 별도 `final_evaluation` 합성 데이터에 한 번 적용했다. **최종 판정은 불통과**다. 전체 표본의 IPCW Brier는 모든 경과일에서 원본 AFT보다 낮지만, 구매 간격 이력 0개·경과 7일 구간의 오차가 악화되어 사전 규칙을 충족하지 못했다. 이는 합성 데이터에서 평가 절차를 검증한 결과일 뿐이며 실제 사용자 품질이나 확률 공개 승인이 아니다. 해당 최종 평가본을 사용한 재조정은 하지 않는다.

## 동결 범위와 분리

- 개발 데이터: `calibration_development-9201-20430717`, 주문 21,261건. 개발 전용 후보 비교에서 전체 및 저이력(0개, 1~2개) 4개 경과일의 점추정 Brier 비악화 스크린을 통과했다.
- 최종 데이터: `final_evaluation-9202-20450707`, 주문 21,461건. 개발 결과·후보 코드·평가 코드·양쪽 데이터 manifest SHA-256을 `independent_history_logistic_freeze_20261005.json`에 먼저 고정했다. 입력 검증과 개발 계수 재현을 통과한 뒤에만 최종 정답을 읽었다.
- 후보: AFT 원확률의 log-odds, 이력 0개/1~2개 표시와 상호작용을 사용하는 L2 logistic 보정(C=1). 내부 보정 표본에서 학습하고, 바깥 개발 Validation으로 후보를 선택했다.
- 판정 규칙: 경과 0·7·14·30일에서 전체 및 두 저이력 집단의 IPCW Brier 점추정이 원본 AFT보다 모두 나빠지지 않아야 한다. 사용자 단위 Bootstrap 1,000회(seed 42)는 불확실성 진단이며 사후 규칙 변경에 쓰지 않았다.
- 최종 결과 JSON: `/private/tmp/repurchase-history-logistic-final-20261005-v7.json` (SHA-256 `d3a71ebec722fe0fd7baccb11fa4ca8535d553c9bbffb8da4517a9f7ee48d9f8`). 원천 CSV와 개별 예측은 저장소에 포함하지 않는다.

## 다음 판단

이 후보는 기각하고 동일한 최종 합성 데이터를 추가 후보 선택에 재사용하지 않는다. 새로운 보정 가설은 새 개발 데이터와 **미사용 최종 데이터**를 먼저 분리·동결해야 한다. 실제 서비스 확률 공개 여부는 별도의 운영 데이터 평가와 저이력·시점별 안정성 검증 전까지 **NO-GO**다. `SHADOW` 결과를 `PUBLISHED`로 바꾸거나 정기 CronJob을 활성화하는 근거로 사용하지 않는다.
