# 재구매 Validation·Test 모집단 변화 사후 진단

동일한 2026-10-03 로컬 목데이터 스냅샷으로 두 기간을 각자의 관측 종료 컷에서 복원했다. 기존 Validation·최종 Test의 원천 SHA-256과 결과 파일을 검증했고, 재구성한 표본 수·정답 확인 수·IPCW 가중 관측률이 저장된 평가와 일치했다. 새 독립 평가, 모델 재선택 또는 확률 보정이 아니다.

| 기간 | 전체 앵커 | 정답 확인 | 사용자 | IPCW 가중 30일 재구매율 |
| --- | ---: | ---: | ---: | ---: |
| Validation | 19,189 | 13,625 | 3,271 | 15.88% |
| Test | 34,895 | 24,029 | 4,057 | 27.72% |

전체 관측률 차이는 **+11.84%p**다. 사용자 수는 전체 앵커 기준이므로 정답 확인 행만 사용하는 Bootstrap의 사용자 수와 다를 수 있다.

| 구간 | Validation 전체 표본 비중 | Test 전체 표본 비중 | Validation 구간 관측률 | Test 구간 관측률 |
| --- | ---: | ---: | ---: | ---: |
| 구매 간격 0개 | 61.27% | 52.80% | 8.55% | 12.75% |
| 구매 간격 1개 | 15.86% | 15.23% | 20.14% | 32.24% |
| 구매 간격 2개 이상 | 22.87% | 31.98% | 33.11% | 51.62% |
| 과거 주문 0건 | 15.03% | 9.39% | 10.50% | 13.42% |
| 과거 주문 1건 | 10.76% | 7.25% | 12.31% | 20.86% |
| 과거 주문 2~3건 | 16.11% | 11.37% | 15.47% | 25.71% |
| 과거 주문 4건 이상 | 58.10% | 71.99% | 18.13% | 31.28% |

표본 비중은 전체 앵커 기준이고 구간 관측률은 정답 확인 행의 IPCW 가중치 기준이다. 따라서 이 표의 비중과 관측률을 직접 곱해 전체 관측률을 재계산하면 안 된다.

IPCW **가중치 비중**과 구간 관측률을 사용해 전체 +11.84%p를 기술적으로 분해했다. Validation 구간 관측률을 고정했을 때 구간 구성 변화의 몫은 구매 간격 기준 **+2.02%p**, 과거 주문 수 기준 **+0.58%p**다. 나머지 구간 내 관측률 변화는 각각 **+9.82%p**, **+11.26%p**다. 두 축은 같은 차이를 각기 분해한 것이므로 서로 더하지 않는다.

즉 이력 많은 표본의 비중 증가만으로 전체 차이를 설명할 수 없다. 각 이력 구간에서도 Test 관측률이 더 높았다. 이는 **모집단·기간 변화에 대한 기술적 관찰**이지 원인 규명이나 운영 데이터로의 일반화는 아니다. 두 기간은 같은 생성 목데이터에서 나왔고, 검열·시간 효과·데이터 생성 설정의 영향을 분리하지 못한다. 기존 Test를 보고 보정기를 맞추거나 AFT/LightGBM을 바꾸지 않으며, 사용자 확률 공개는 계속 **NO-GO**다.
