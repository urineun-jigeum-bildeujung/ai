# 재구매 예측용 목데이터 생성 가이드

## 1. 기준 데이터와 사용 범위

| 데이터 | 확인한 범위 | 이번 가이드에서 사용하는 부분 | 그대로 사용하지 않는 부분 |
| --- | --- | --- | --- |
| UCI Online Retail II | 2009-12~2011-12, 1,067,371개 거래 행 | 취소·음수·사용자 누락 사례, 장기 관측 시 상품 재구매 간격의 긴 꼬리 | 영국 선물용품·도매 수량과 금액 |

공개 데이터는 목데이터의 분포와 예외 조건을 정하는 참고값이다. 국내 반려동물 소비자의 시장 통계나 모델 성능의 대체 근거로 표현하지 않는다.

## 2. 10만 건의 기준 단위

`10만 건`은 `order_items` 100,000행으로 정의한다. 주문 수와 사용자 수를 각각 10만 건으로 부르면 팀마다 생성 결과가 달라지므로 반드시 단위를 고정한다.

권장 시작 범위는 다음과 같다.

| 대상 | 초기 생성값 | 근거·용도 |
| --- | ---: | --- |
| `order_items` | 100,000행 | 생성 목표 고정 단위 |
| `orders` | 약 45,100건 | 반려동물 부분집합의 주문당 상품 행 평균 2.217개로 역산 |
| `users` | 약 6,600명 | 초기 활동 세그먼트 구성의 사용자당 주문 기대값 약 6.87회로 역산 |
| 관측 기간 | 18~24개월 | 95분위 구매 간격이 약 128~162일까지 이어지고 중도절단을 관측할 수 있도록 구성 |
| 유효 결제 상품 | 전체의 97~99% | UCI 명시적 취소 1.83%, Complete Journey 비유효 후보 0.77% 참고 |

사용자 수·주문 수·주문상품 수를 각각 독립적인 목표값으로 정하지 않는다. 다음 관계를 만족하도록 생성 설정에서 계산한다.

- `예상 order_items = 예상 orders × 주문당 상품 행 기대값`
- `예상 orders = users × 사용자당 주문 기대값`

초기값은 `100,000 ÷ 2.217 ≈ 45,100개 주문`, `45,100 ÷ 6.87 ≈ 6,600명`으로 계산했다. 최종 행 수를 정확히 100,000건으로 맞추기 위해 마지막 단계에서 사용자를 임의로 늘리거나 주문을 잘라내지 않고, 목표 근처에서 생성한 뒤 독립적인 주문 단위로 보정한다. 실제 서비스 규모 시연을 위해 사용자 수를 늘리고 싶다면 활동 세그먼트 비율 또는 주문당 상품 수를 함께 다시 계산해야 한다.

## 3. 반드시 보존할 데이터 관계

각 행을 독립 난수로 만들지 않고 다음 순서로 생성한다.

1. `users`와 `pet_profile`을 생성한다.
2. 사용자마다 신규·저빈도·반복·고빈도 활동 세그먼트를 배정한다.
3. 사용자·반려동물별로 구매할 카테고리와 상품군 구성을 배정한다.
4. 사용자·반려동물·상품군별 잠재 소비주기와 변동성을 먼저 생성한다.
5. 상품 용량·구매 수량을 반영해 시간순 구매 의도 이벤트를 생성한다.
6. 서로 가까운 시점에 발생한 동일 사용자의 구매 의도를 하나의 `orders`로 묶고 `order_items`를 연결한다.
7. 일부 주문에 취소·반품·상품 변경 시나리오를 주입한다.
8. 생성 결과의 사용자 전체 주문 간격과 주문당 상품 수가 목표 분포를 만족하는지 확인하고 설정을 조정한다.
9. 모든 이벤트를 생성한 뒤 시간 기준으로 학습·검증·테스트 구간을 나눈다.

상품 소비주기와 사용자 전체 주문 간격을 각각 독립 난수로 만들지 않는다. 상품별 구매 의도에서 주문이 파생되어야 두 시간 분포와 장바구니 구성이 서로 모순되지 않는다. `train`, `validation`, `test`를 각각 따로 난수 생성하거나 행 단위로 무작위 분할하지 않는다.

## 4. 반려동물 카테고리 기준 분포

Complete Journey 반려동물 부분집합에서 확인한 기준값이다.

| 카테고리 | 카테고리 2회 이상 구매 사용자 | 동일 상품 반복 사용자 | 동일 상품 간격 25분위 | 중앙값 | 75분위 | 95분위 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| CAT FOOD | 70.07% | 49.34% | 8.91일 | 18.43일 | 42.16일 | 128.03일 |
| DOG FOODS | 69.18% | 48.05% | 11.81일 | 22.22일 | 49.06일 | 146.04일 |
| PET CARE SUPPLIES | 49.64% | 20.04% | 11.75일 | 26.99일 | 60.03일 | 162.02일 |

목데이터는 하나의 평균 주기로 통일하지 않는다.

- 사료 계열은 동일 상품 반복 사용자를 약 45~55% 범위로 둔다.
- 용품 계열은 동일 상품 반복 사용자를 약 15~25% 범위로 둔다.
- 구매 간격은 정규분포보다 95분위까지 길게 이어지는 오른쪽 꼬리 분포를 사용한다.
- 고양이 모래·배변패드·영양제는 공개 부분집합에 직접 대응하는 구분이 없으므로 별도 도메인 가정값으로 표시한다.
- 도메인 가정값을 실데이터 기준값과 섞어 하나의 근거 수치처럼 표현하지 않는다.

### 사건 가중 간격과 사용자별 대표 주기의 분리

| 데이터 범위 | 모든 사건을 합친 구매 간격 중앙값 | 사용자·상품별 중앙 주기의 중앙값 | 쌍별 주기 CV 중앙값 | CV 계산 가능 쌍 |
| --- | ---: | ---: | ---: | ---: |
| UCI 전체 | 56.03일 | 82.97일 | 0.685 | 55,444쌍 |
| Complete Journey 반려동물 | 20.86일 | 34.81일 | 0.687 | 1,525쌍 |

모든 구매 간격을 한데 합치면 구매 횟수가 많은 사용자·상품 쌍이 여러 번 포함되어 짧은 간격이 전체 분포를 더 강하게 지배한다. 목데이터 생성에서는 다음 두 단계를 분리한다.

1. 사용자·반려동물·상품군마다 잠재 소비주기를 먼저 생성한다. 이 단계는 각 쌍을 한 번씩 반영한 `사용자·상품별 중앙 주기` 분포를 기준으로 한다.
2. 실제 주문 시점은 잠재 소비주기 주변에서 개인별 변동성을 반영해 생성한다. 변동성은 쌍별 `CV = 간격 표준편차 ÷ 간격 평균` 분포를 참고한다.

반려동물 쌍별 CV는 중앙값 0.687, 95분위 1.335로 변동 폭이 작지 않았다. 다만 CV는 간격이 2개 이상, 즉 같은 상품 구매가 최소 3회 관측된 쌍에서만 계산 가능하다. 반려동물 반복 쌍 중 계산 가능한 1,525개 쌍의 관찰값이라는 한계를 기록하고, 이력 2회 사용자의 변동성까지 대표하는 값으로 해석하지 않는다.

정규분포·로그정규분포·감마분포 중 어떤 분포족으로 잠재 주기와 오차를 생성할지는 적합도와 생성 후 분위수 재현 결과를 비교한 뒤 결정한다. 현재 단계에서는 특정 분포족을 근거 없이 확정하지 않는다.

## 5. 사용자 활동성 분포

모든 사용자에게 같은 주문 수를 배정하지 않는다. 다음 세그먼트가 섞이도록 생성한다.

| 세그먼트 | 주문 수 | UCI 관찰 비율 | 반려동물 부분집합 관찰 비율 | 초기 생성 비율 | 생성 목적 |
| --- | ---: | ---: | ---: | ---: | --- |
| 신규·단발 | 1회 | 27.65% | 24.85% | 26% | 콜드스타트 및 중도절단 |
| 저빈도 | 2~3회 | 27.34% | 23.88% | 26% | 낮은 신뢰도 예측 |
| 반복 | 4~10회 | 30.11% | 30.93% | 30% | 일반적인 개인 소비주기 학습 |
| 고빈도 | 11회 이상 | 14.90% | 20.35% | 18% | 긴 이력과 극단 사용자 테스트 |

초기 생성 비율은 UCI와 Complete Journey 반려동물 부분집합을 동일 가중 평균한 뒤 합계가 100%가 되도록 정수 비율로 조정한 설정값이다. 두 공개 데이터가 국내 자체 이커머스 모집단을 대표한다는 뜻은 아니며, 실제 서비스 로그가 쌓이면 동일 집계 코드로 다시 계산해 교체한다.

세그먼트 내부 주문 수에도 다음 조건을 둔다.

- 신규·단발 사용자는 정확히 1회 주문한다.
- 저빈도 사용자는 두 데이터 모두 중앙값 2회이며 약 41%가 3회였으므로, 초기에는 2회 60%·3회 40%로 생성한다.
- 반복 사용자는 중앙값 6회, 95분위 10회를 목표로 하며 4~10회 구간의 경험적 히스토그램을 기준으로 생성한다.
- 고빈도 사용자는 중앙값 16~17회, 95분위 46~55회를 목표로 긴 오른쪽 꼬리를 유지한다.
- UCI의 최대 398회는 도매·고빈도 거래의 영향을 받을 수 있으므로 그대로 복제하지 않는다. 초기 상한은 반려동물 부분집합 최대 73회와 UCI 95분위 55회를 참고해 75회로 제한하고, 제한 여부를 생성 설정에 기록한다.

Complete Journey 전체에서는 고빈도 사용자가 87.28%로 나타났지만, 이는 1년간 반복 관찰된 식료품 패널의 표본 구조이므로 자체 신규 이커머스 사용자 비율로 사용하지 않는다. 고빈도 사용자는 전체의 일부로 두고 상한을 적용해 특정 사용자가 10만 행 대부분을 차지하지 않도록 한다.

## 6. 주문 구성 분포

Complete Journey 반려동물 부분집합의 한 주문에는 평균 2.217개, 중앙값 1개, 95분위 6개의 반려동물 상품 행이 있었다.

| 주문 내 반려동물 상품 행 | 관찰 비율 |
| ---: | ---: |
| 1개 | 55.19% |
| 2개 | 18.92% |
| 3개 | 8.92% |
| 4개 | 6.08% |
| 5개 | 3.58% |
| 6개 | 2.46% |
| 7개 이상 | 4.85% |

- 주문당 상품 행 수는 위 경험적 빈도표를 기준으로 샘플링한다.
- 전체 UCI의 주문당 상품 행 중앙값 15개는 선물용품·도매 주문 구조의 영향이 커 반려동물 자체 이커머스 기준으로 사용하지 않는다.
- 반려동물 부분집합에서는 한 주문 안의 중복 상품 행과 상품별 주문 시각 불일치가 관측되지 않았다. 자체 목데이터에서도 동일 상품은 한 `order_item`에 수량으로 표현하고 주문상품의 기준 주문 시각은 `orders.paid_at`을 참조한다.
- 향후 장바구니·결제 구현상 한 주문에 동일 SKU가 여러 행으로 저장될 수 있다면 생성 규칙을 바꾸기 전에 백엔드 스키마 계약을 먼저 확인한다.

## 7. 수량·용량 생성 규칙

Complete Journey의 반려동물 용품 주문 수량은 중앙값 1개, 95분위 3개였다. 반면 고양이·강아지 사료는 캔 묶음과 중량 코딩 영향으로 수량 95분위가 각각 16개, 10개까지 나타났다.

이전 구매 수량과 다음 동일 상품 구매 간격의 Spearman 순위 상관은 CAT FOOD `-0.147`, DOG FOODS `-0.203`, PET CARE SUPPLIES `-0.063`으로 나타났다. 공개 데이터의 단순 `quantity`에서는 구매 수량이 많을수록 다음 구매가 늦어진다는 관계가 확인되지 않았다. 포장 용량, 묶음 단위, 반려동물 수·체중, 프로모션이 분리되지 않은 필드이므로 이 상관을 자체 서비스의 소비량 관계로 복제하지 않는다.

우리 데이터에서는 `quantity`와 상품 용량을 분리한다.

- 일반 주문의 `quantity`는 1개를 최빈값으로 하고 대부분 1~3개 범위로 생성한다.
- 다묶음 상품은 `quantity=12`로 만들기보다 `net_quantity_value`, `net_quantity_unit`, `normalized_quantity_g`에 포장 용량을 저장한다.
- 총 확보 용량은 `quantity × normalized_quantity_g`로 계산한다.
- 사료·모래·패드처럼 용량 기반 소비가 가능한 상품은 사용자·반려동물별 잠재 일일 소비량을 먼저 생성하고 `기대 소비일수 = 총 확보 용량 ÷ 잠재 일일 소비량`으로 다음 구매 기준을 만든다.
- 총 확보 용량과 기대 간격의 양의 관계는 공개 데이터 `quantity`에서 검증된 시장 통계가 아니라, 물리적 소비 과정이 모순되지 않도록 적용하는 도메인 생성 규칙으로 표시한다.
- 실제 소비 간격에는 개인별 CV, 조기 추가 구매, 프로모션, 상품 전환 시나리오를 적용해 용량에 완전히 비례하지 않도록 한다.
- 수량·용량·다음 구매일을 서로 독립 난수로 생성하지 않는다.

- UCI 0 이하 수량: 2.15%
- Complete Journey 0 이하 수량: 0.60%
- Complete Journey 0 이하 결제금액: 0.76%

### 자체 서비스 목데이터 적용

- `user_id`는 자체 로그인 서비스의 필수 FK이므로 누락시키지 않는다.
- `pet_id` 미지정 주문은 사용자 단위 fallback 검증용으로 별도 비율을 설정할 수 있다.
- 취소·반품·부분반품은 전체 상품의 약 1~3% 범위에서 생성하되 `order_status`, `item_status`, `cancelled_quantity`, `returned_quantity`가 서로 모순되지 않아야 한다.
- 유효 구매 수량 `quantity - cancelled_quantity - returned_quantity`가 1 이상인 행만 재구매 라벨 생성 대상이다.
- 결측·이상 행은 실수처럼 무작위로 흩뿌리는 것이 아니라 검증하려는 예외 코드와 연결해 생성한다.

## 9. 상품 변경을 이상치가 아닌 행동 신호로 생성

사용자가 예상 소비주기보다 이른 시점에 같은 카테고리의 다른 `product_group_id`를 구매하면 무조건 제거하지 않는다.

### 공개 데이터에서 관찰한 전환 구조

| 카테고리 | 첫 후속 주문 상품 전환 | 전환 중 이른 전환 | 다음 주문 새 상품 유지 | 다음 주문 이전 상품 복귀 |
| --- | ---: | ---: | ---: | ---: |
| CAT FOOD | 68.42% | 20.70% | 25.99% | 19.77% |
| DOG FOODS | 71.29% | 30.36% | 25.64% | 18.95% |
| PET CARE SUPPLIES | 86.41% | 12.91% | 16.20% | 13.73% |

전환은 같은 사용자·카테고리의 직전 주문과 현재 주문이 모두 단일상품 주문일 때만 판정했다. 동일 카테고리 상품을 여러 종 함께 산 주문은 전환 대상이 모호하므로 판정에서 제외하고 별도 비율로 보존했다. 다상품 주문 비율은 CAT FOOD 45.55%, DOG FOODS 32.45%, PET CARE SUPPLIES 17.79%였다.

`이른 전환`은 임의의 고정 일수가 아니라 해당 카테고리의 동일상품 반복 간격 25분위보다 짧은 전환으로 정의했다. fallback 기준은 CAT FOOD 8.01일, DOG FOODS 11.92일, PET CARE SUPPLIES 7.27일이다. 실서비스에서는 사용자별 예측구간 하한이 있으면 개인 기준을 우선한다.

위 수치는 해외 식료품 패널에서 관찰한 상품 ID 변경 구조이며 불만족률을 뜻하지 않는다. 재고·판촉·맛 다양화·규격 변경이 구분되지 않으므로 국내 사용자 피드백 비율이나 변경 사유 분포로 해석하지 않는다.

1. 기존 상품 구매 후 짧은 기간 안에 동일 카테고리의 새 상품을 구매한다.
2. `price`, `palatability`, `adverse_reaction`, `stockout`, `promotion`, `other` 중 변경 사유 시나리오를 연결한다.
3. 새 상품을 기준 횟수 이상 반복 구매하면 만족 사유 후속 피드백 시나리오를 생성한다.
4. 모델 입력에서는 `product_switched`, `days_since_previous_product`, `switch_reason_code` 같은 파생 피처로 사용할 수 있게 원천 이벤트를 보존한다.

첫 구매 후 다음 동일 카테고리 주문에서 다른 상품을 고르거나, 개인 예측 하한보다 이르게 다른 상품을 구매하면 변경 사유 질문 트리거 후보로 표시한다. 새 상품을 한 번 더 산 것만으로 만족이 확정됐다고 보지 않고, 프로젝트에서 합의한 반복 구매 기준을 충족했을 때만 만족 사유 질문을 생성한다.

전환 행동 자체는 공개 데이터 관찰값을 참고할 수 있지만 `price`, `palatability`, `adverse_reaction` 같은 변경 사유 비율과 만족 사유는 거래 데이터에 존재하지 않는다. 이 필드는 **시연 시나리오 가정값**으로 관리하고 생성 데이터의 원천을 `scenario_assumption`으로 표시한다. 실제 서비스 피드백이 쌓이면 해당 분포로 교체한다.

## 10. 중도절단과 시간 분할

### 사용자 전체 주문 간격 검증값

| 데이터 범위 | 모든 주문 사건 간격 중앙값 | 사용자별 중앙 주문 간격의 중앙값 | 사용자별 주문 간격 CV 중앙값 |
| --- | ---: | ---: | ---: |
| UCI 전체 | 24.95일 | 55.99일 | 0.833 |
| Complete Journey 반려동물 | 13.90일 | 28.49일 | 0.773 |

사용자는 특정 상품을 다시 사기 전에도 다른 카테고리 상품을 구매하므로 사용자 전체 주문 간격은 동일 상품 소비주기보다 짧게 나타난다. 이 분포는 상품별 구매 의도를 주문으로 묶은 뒤의 결과 검증값으로 사용하며, 상품 소비주기와 별도로 독립 샘플링하지 않는다.

월·요일·시간대별 분포도 산출하지만 공개 데이터의 국가·시간대·관측 기간이 국내 서비스와 다르므로 시각적 시연 트래픽의 참고값으로만 사용한다. 국내 시간대 분포라는 근거로 표현하지 않는다.

상품 단위 마지막 구매의 사건 기준 중도절단 비율은 다음과 같았다.

- UCI 전체: 62.68%
- Complete Journey 전체: 59.10%
- Complete Journey 반려동물 부분집합: 50.95%

마지막 구매 뒤에 다음 구매가 보이지 않는다고 `재구매 안 함`으로 확정하지 않는다. 관측 종료일까지 재구매가 확인되지 않은 중도절단 행으로 저장한다.

- `as_of_timestamp` 이후 데이터를 피처에 포함하지 않는다.
- 시간 순서대로 train → validation → test를 구성한다.
- 분할 경계와 관측 종료일은 `dataset_generation_runs`에 기록한다.
- 회귀 모델에서는 다음 구매가 관측된 행만 학습하거나 별도 하한 라벨 정책을 사용한다.
- 생존분석에서는 마지막 미관측 행을 중도절단 표본으로 포함한다.

## 11. 생성 결과 검증 기준

### 무결성

- PK 중복 0건
- 필수 FK 고아 레코드 0건
- `paid_at < ordered_at` 0건
- 취소·반품 수량이 최초 수량보다 큰 행 0건
- 사용자별 주문 시각 역전 0건
- 상품 용량 단위 변환 실패 0건

### 분포

- 카테고리별 반복 사용자 비율은 목표 범위에서 ±3%p 이내
- 구매 간격 25·50·75·95분위는 설정한 기준에서 각각 ±15% 이내
- 주문당 상품 수와 수량의 중앙값·95분위를 함께 확인
- 사용자당 주문 수의 중앙값과 95분위를 함께 확인
- 전체 분포뿐 아니라 카테고리·사용자 활동 세그먼트별 조건부 분포도 확인

### 재현성

- 난수 seed 고정 가능
- 생성기 버전·설정 파일·생성 시각 기록
- 동일 seed와 동일 설정으로 같은 결과 재생성 가능
- 생성 전후 검증 결과를 `dataset_generation_runs`와 보고서에 연결

## 12. 사용하면 안 되는 생성 방식

- 10만 행을 사용자·주문 관계 없이 독립적으로 랜덤 생성
- 모든 카테고리에 같은 평균 소비주기 적용
- 구매 간격에 대칭 정규분포를 적용해 0 이하 간격이 생기게 함
- 수량·상품 용량·다음 구매일을 서로 독립적으로 생성
- 마지막 구매를 전부 음성 라벨로 처리
- train·validation·test를 따로 생성하거나 행 단위 무작위 분할
- 공개 데이터 수치를 국내 반려동물 시장의 대표 통계로 표현
