# 재구매 예측 실험 수치와 의사결정 기록

## 2026-09-17 · LightGBM 30일 내 재구매 확률

UCI Online Retail II에서 같은 사용자의 동일 상품 재구매를 예측했다.
반려동물 서비스 실사용 데이터에 대한 성과가 아니라 공개 이커머스 데이터의
시간 분리 Validation 결과다. 다음 구매일까지의 오차(MAE)와 30일 내 구매
확률 오차(Brier)는 서로 다른 평가이므로 함께 혼용하지 않는다.

| 항목 | 기록 |
| --- | --- |
| 학습 입력 | 정답이 확인된 Train 473,572행, IPCW 가중치 사용 |
| 평가 전체 | Validation 97,340행 |
| 30일 결과 확인 | 73,542행. 나머지를 미재구매 정답으로 바꾸지 않음 |
| 비교 기준 | 계층형 재구매 확률 모델, 상품 수축 강도 k=8 |
| 후보 | 과거 구매 이력 피처 4개의 LightGBM 이진분류 |
| 기준 / 후보 Brier | 0.0978098525 / 0.0822656220 |
| Brier 절대 감소 | 0.0155442306 |
| Brier 상대 감소 | **15.8923%** = (기준 − 후보) / 기준 × 100 |
| 평균 Calibration 오차(ECE) | 0.0104036444 → 0.0371831821로 악화 |
| Bootstrap | 정답 확인 표본에 포함된 사용자 1,926명을 단위로 1,000회 복원추출, seed=42 |
| 개선량 95% percentile 구간 | +0.0056639900 ~ +0.0301293953 |
| 개선된 Bootstrap 반복 | 1,000/1,000회. 정확도 100% 또는 향후 개선 확률 100%가 아님 |

Bootstrap은 학습된 두 모델의 예측을 고정하고 사용자 구성을 재표집했다.
매 반복마다 모델을 재학습하거나 검열 가중치를 재추정한 결과가 아니므로
학습 데이터 변동·검열모형 추정·모델 선택·미래 분포 변화에 따른 전체
불확실성을 포함하지 않는다. 이 구간은 C와 k=8의
비교에만 적용하며 B와 C의 차이에 재사용하지 않는다.

증거:

- [Bootstrap 1,000회 원자료](uci_lightgbm_vs_k8_bootstrap_trials.json)의 `summary`, `trials`
- 구현 커밋 `7c9aefb`, 결과 커밋 `1aacdbe`

계층형 확률 기준선 대비 Brier는 감소했지만 ECE는 증가했다. 전체 확률 오차와
확률 보정 수준이 같은 방향으로 변하지 않았으므로, 보정 곡선과 구간별 성능을
추가 확인한 뒤 모델을 판단한다.

## 피처 단계별 추가 비교

| 후보 | 입력 | IPCW Brier | ECE | 직전 후보 대비 Brier 상대 감소 |
| --- | --- | ---: | ---: | ---: |
| A | 과거 구매 간격 수 + 사용자 과거 주문 수 | 0.0929649191 | 0.0654204353 | 해당 없음 |
| B | A + 과거 구매 간격 중앙값 | 0.0828554197 | 0.0371501148 | 10.8745% |
| C | B + 구매 간격 상대 MAD | 0.0822656220 | 0.0371831821 | 0.7118% |

- 동일한 학습·평가 행, 정답, 가중치, 모델 설정을 사용했다. 결측 피처 때문에
  후보별로 표본을 추가 삭제하지 않았다.
- Brier 개선량은 A→B +0.0101094994, B→C +0.0005897978이다.
- 단계적 추가 순서에 조건부인 비교이며 개별 피처의 독립적 인과 효과는 아니다.
- C의 Brier·ECE·MCE와 시간 분할이 기존 네 피처 실행 결과와 일치했다.
- B와 C 사이의 작은 개선은 아래 사용자 단위 쌍 비교 Bootstrap으로 추가
  검증했다.

다만 절대 개선 폭은 작으므로 압도적인 우위로 표현하지 않는다. 모델 재학습,
검열모형 재추정, 피처 선택과 미래 데이터 분포의 불확실성은 이 구간에 포함되지
않는다. Validation 탐색 결과이며 최종 Test 성능이 아니다.

## 강사 피드백 반영 · 2026-09-17

| 피드백 | 현재 확인된 내용 | 후속 검증 |
| --- | --- | --- |
| ECE 악화에 대해 Calibration curve 확인 | 확률 구간별 IPCW 보정 통계를 저장했고 ECE·MCE를 계산함. 곡선 해석은 아직 진행 전 | 동일한 30일 시점·확률 구간에서 k=8·B·C 곡선을 비교하고 과신·과소신뢰 방향 확인 |
| 횟수 → 구매 간격 → 불규칙성 순으로 추가 | A/B/C 비교 완료. 중앙값 추가 시 Brier 절대 감소 0.0101095, 불규칙성 추가 시 0.0005898. B/C 사용자 Bootstrap 95% 구간은 +0.0000342~+0.0014568 | Calibration curve에서 작은 Brier 개선과 보정 오차 방향을 함께 확인 |
| 이력과 prior 근거량별 성능 분리 | 기존 중앙값 모델의 오차 원인 분석은 수행함. 새 LightGBM과 k=8의 동일 세그먼트 확률 성능 비교는 아직 진행 전 | 개인 이력 수·사용자 과거 주문 수·상품 prior 관측 수별 Brier와 Calibration 비교 |
| AFT를 Brier·C-index·Calibration으로 비교 | XGBoost AFT는 후속 별도 실험 | 같은 예측 대상·시간 분할·30일 시점·검열 처리 조건으로 공통 지표 비교 |

Brier는 확률 예측의 종합 오차 지표다. Brier 감소만으로 특정 분류 임계값에서의
Precision·Recall 개선을 확정하지 않는다. ECE는 편차의 크기를 요약하므로 과신과
과소신뢰 방향은 곡선으로 확인한다.

Calibration curve는 가로축에 구간별 IPCW 가중 평균 예측 확률, 세로축에
IPCW 가중 관측 재구매율을 둔다. 기준선 `y=x` 아래는 관측률보다 높은 확률을
예측한 구간, 위는 낮은 확률을 예측한 구간이다. 구간별 표본 수·가중치 합도
함께 보며 소표본 구간 하나로 전체 보정 방향을 단정하지 않는다.

세그먼트는 결과를 본 뒤 유리하게 고르지 않고 기존 분석 구간을 먼저 검토해
고정한다. 세그먼트마다 두 모델에 동일 표본과 공통 평가 가중치를 사용하고,
사용자 수·정답 확인 수·검열 비중도 기록한다. 개인의 과거 간격 수, 사용자의
전체 주문 수, 상품 prior 관측 수는 서로 다른 근거량이므로 구분한다.

AFT는 학습한 생존분포에서 `P(T≤30)`을 산출해 확률 지표를 비교한다.
중앙 예측일을 임의의 확률로 바꾸지 않는다. C-index 비교에서는 사건의 정의,
평가 기간과 검열 가중치, 위험 점수의 방향을 맞춘다. 30일 확률의 순위와
전체 생존시간 예측의 순위는 의미가 다르므로 어떤 점수를 썼는지 명시한다.

진행 순서: B/C 쌍 비교 입력·Bootstrap 완료 → Calibration curve → 이력·prior별
확률 성능 비교 → XGBoost AFT 동일 조건 비교. 각 단계는 기본 코드와
판단 기준을 먼저 설명한 뒤 작은 구현 단위로 나눠 진행한다.
