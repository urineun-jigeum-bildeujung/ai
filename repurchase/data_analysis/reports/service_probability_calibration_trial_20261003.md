# 서비스 조건부 재구매 확률 보정: 로컬 Validation 실험

- 입력: 2026-10-03 로컬 원천 추출본. `order_db` 주문 44,777건·주문상품 100,487건·상태 이력 259,596건·클레임 1,395건·클레임상품 2,592건, `member_db` 반려동물 13,254건. CSV 건수·SHA-256과 오프라인 원천 감사를 확인했다.
- 출처 범위: 작업자가 `petflow-dev` DB 포트포워딩으로 받은 추출본이다. 로컬 manifest는 추출 시각·파일 무결성을 기록하지만, 추출 당시 dev DB 전체가 최신이었다는 독립 증명이나 두 DB 간 원자적 스냅샷은 제공하지 않는다.
- 관측 종료 가정: `2026-10-03T00:00:00+09:00`. 시간 기준 70%를 바깥 Train, 다음 15%를 바깥 Validation으로 사용했다. 바깥 Train의 앞 80%로 AFT를 학습하고 나머지 20%에서 경과 시점별 IPCW 가중 Isotonic 보정기를 학습했다.
- 동일한 내부 Train AFT의 보정 전·후 확률만 같은 바깥 Validation 행에서 비교했다. AFT 설정은 normal, scale 1.0, 20 rounds, 예측 기간은 향후 30일이다. Test는 열지 않았다.

사용자 단위 1,000회 쌍 Bootstrap(seed 42)에서 네 시점 모두 Brier 개선량의 percentile 95% 구간이 0보다 컸다. 각 시점의 위험집단이 다르므로 시점 간 지표 크기를 직접 비교하지 않는다. 이 구간은 **학습된 모델을 고정한 평가 표본 불확실성**만 다루며, 모델·보정기의 재학습 변동성은 포함하지 않는다. 기존 전체 Train으로 학습한 AFT 결과와도 학습 집합이 달라 직접 우열을 판단하지 않는다. 따라서 운영 보정기 채택이나 Test 성능 확정은 아직 아니다.

재현 명령은 `scripts.run_service_probability_calibration`이며, 원천·코드 SHA-256, 시간 컷, 보정 매핑, Calibration 구간과 반복별 Bootstrap 결과를 JSON에 남긴다. 로컬 원천 CSV는 Git에 올리지 않는다.
